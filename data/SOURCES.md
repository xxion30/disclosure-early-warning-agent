## 원천 링크

- [OpenDART](https://opendart.fss.or.kr/)
- [DART 전자공시시스템](https://dart.fss.or.kr/)
- [한국거래소 KIND](https://kind.krx.co.kr/)

공시별 원문은 데이터에 기록된 URL 또는 `https://dart.fss.or.kr/dsaf001/main.do?rcpNo=<접수번호>` 형식으로 추적한다. 목록·재무·감사의견·항목 API의 세부 계약은 [데이터 원천 계약](../docs/contracts/data_sources.md)을 따른다.

## 보관과 개인정보

합성 고객 데이터에는 실제 고객 개인정보가 없다. 다만 일부 공개 공시 원문에는 개인 식별 정보가 있으므로 전체 데이터에 “개인정보 없음”을 일괄 적용하지 않는다. 공개 자료라는 사실과 개인 식별 정보 포함 여부는 별개이며, 최종 제출 시 원문별 공개 범위·마스킹을 검수한다.

고객 실명·연락처의 모델 입력 마스킹과 안내문의 `{고객명}` 자리표시는 공개 공시 전체의 개인정보 제거를 보장하지 않는다. 실제 키는 .env에만 두고 고객 실데이터·로컬 DB·체크포인트·검색 색인을 제출 데이터로 포함하지 않는다.

persistent 검색은 테스트 문서를 Chroma에 적재한다. ephemeral 검색은 DART 원문을 메모리에 색인하고 처리 후 해제하며, 저장소의 테스트 원문 파일을 자동으로 삭제하지 않는다.

최신 정정본 API 값을 과거 접수일의 원본 값으로 소급하지 않는다. 금양 최초 전체 경보 359일은 당시 원본 재무 데이터 검증 대기 결과이며 확정 성과로 사용하지 않는다. 현재 평가 결과와 한계는 [README](../README.md)를 따른다.
