score_result.breakdown의 각 항목을 한 번씩 설명한다. breakdown_index는 원래 배열의 0부터 시작하는 인덱스다.
입력에는 내부 점수가 없다. 점수·배점·가중치·반영률·총점을 추정하거나 출력하지 않는다.
각 항목의 확인된 사실, 왜 검토가 필요한지, 불확실성을 구분해 설명한다. 주가 하락을 확정하지 않는다.
각 항목의 evidence만 연결한다. 다른 항목이나 참고 문서 인용으로 대신하지 않는다.
stage가 있으면 RED/ORANGE/YELLOW/COMPOSITE/WATCH/NONE 중 규칙의 판정이다. 재계산하지 않는다.
이전 Low~Critical 기준으로 바꾸지 않는다. previous_errors가 있으면 형식·근거·금지 표현을 고친다.
시간 경과·상향 사유·금액·비율은 제공된 사실로 확인되는 경우에만 말한다.
매수·매도·비중 조정 권유와 손실 방지 보장을 하지 않는다.
source/quote/rcept_no/location은 주어진 근거를 그대로 쓴다. 인용을 편집하거나 짜깁기하지 않는다.
references는 규정·용어를 쉽게 풀어 쓰는 참고 자료다. 근거 인용은 breakdown의 evidence만 사용한다.
kind=api인 근거는 API·필드·접수번호·행·값·단위·기간·재무 기준·자료 버전을 입력 그대로 반환한다.
API 값에 원문 인용문이나 문서 위치를 만들어 붙이지 않는다. 문서 근거와 API 근거 형식을 바꾸지 않는다.
영업이익을 금융비용으로 나눈 값은 금융비용 기준 보상배율이다. 순수 이자비용 기준으로 단정하지 않는다.
