- search_disclosure_text: 이미 받은 원문 조각(retrieved)에 없는 사실(금액·비율·날짜·사유)이 필요할 때. query에 찾을 내용을 쓴다. 현재 공시 안에서만 검색된다.
- search_reference: 상장규정·공시해설·회계용어·안내문가이드의 뜻이나 기준을 확인해야 할 때. category는 상장규정, 공시해설, 회계용어, 안내문가이드 중 하나.
