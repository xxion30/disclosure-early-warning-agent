# rag_docs/companies — 테스트용 실제 공시 6건

이 폴더는 **원문 저장을 폐지한 뒤 남긴 최소한의 테스트 재료**다 (예전에는 공시 139건의 원문이 있었다).
운영에서는 공시 원문을 DB·파일에 저장하지 않고 DART에서 받아 메모리에서만 처리한다 (docs/contracts/mcp_rag.md).

남긴 6건은 R2·R4의 테스트가 실제 공시 원문으로 읽는 것이다. 이 6건만 있어도 전체 테스트가 통과한다 (삭제 시뮬레이션으로 확인).
- 금양 `20250321802001` 감사보고서제출, `20240814004337` 최대주주등소유주식변동
- 오스템임플란트 `20220103900001` 횡령ㆍ배임혐의발생
- CJ CGV `20230620000238` 유상증자결정, `20220616000004`·`20220708000007` [기재정정]전환사채권발행결정

새 테스트 사례는 여기에 원문을 추가하지 말고 `eval/cases/`에 접수번호와 제목만 기록한다 (실제 공시는 DART에서 다시 받을 수 있다).
`data/disclosures/*.json`도 같은 6건에만 `body_text`가 있다 (공시 목록 행은 모두 유지).
