# 안내문 작성 가이드

## 목적
PB가 고객에게 **사실을 알리고 상담을 제안**하는 글이다. 투자 판단을 대신하지 않는다.

## 꼭 지킬 것
1. 고객 이름은 `{고객명}` 자리표시로만 쓴다. 실제 이름은 화면에서만 채워진다.
2. 어떤 공시가 언제 접수되었는지(공시 제목, 날짜)를 적는다.
3. 공시의 어떤 내용이 위험 신호로 읽히는지 한두 문장으로, 원문 근거에 있는 말만 쓴다.
4. 고객이 보유한 종목이라는 사실과 상담 가능 시간 안내로 끝맺는다.
5. 4~6문장, 존댓말.

## 쓰지 않는 표현
- 매수·매도·비중 조절 권유: "매도하세요", "매수하세요", "비중을 줄이세요" 등
- 단정·과장: "반드시", "확실히", "무조건", "100%"
- 손실·수익 약속: "손실을 피하", "수익을 보장"
- (harness/guardrails.py의 목록이 기준이다. 목록은 팀이 같이 고친다.)

## 좋은 예
> {고객명}님, 안녕하세요. 보유하고 계신 OO 종목과 관련해 [날짜]에 "감사보고서제출" 공시가 접수되어 안내드립니다. 공시에는 감사인이 의견을 표명하지 않았다는 내용이 포함되어 있습니다. 공시 내용과 향후 일정에 대해 편하신 시간에 상담드릴 수 있으니 말씀해 주세요.

## 나쁜 예
> {고객명}님, 곧 상장폐지되니 반드시 지금 매도하세요.  ← 매도 권유 + 단정 + 근거 없음
