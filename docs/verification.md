## 평가 결과 — R5 사례 · 규칙 엔진만 (2026-10-23)

### 무엇을 채점했나
- **사례**: R3의 공시 한 건 사례(`eval/cases/r3_cases.json`)와 R5 사례(`eval/cases/r5_cases.json`).
  R5는 R3와 겹치지 않게 **기간 사례**를 맡는다 — 회귀 타임라인 3건(금양·CJ CGV·SK, 각 12개월)과 정상 회사 3건(현대차·NAVER·LG전자, 2024 사업보고서까지 12개월).
- **만드는 법**: `uv run python scripts/demo/build_r5_cases.py` — DART 공시 목록(list.json)의 실제 접수번호·제목·날짜, 재무 지표는 R3 수집기(`collector.indicators`)를 DART 재무제표·감사의견 API에 돌린 값, 사건 공시 값은 항목 API 원본. 지어낸 값은 없다. (DART_API_KEY 필요)
- **채점하는 법**: `uv run python scripts/demo/eval_cases.py --write` — 공시 종류는 `rules.yaml`의 제목 분류, 단계는 `risk_engine`이 계산한다. AI·모델 비용·DART 호출 없음.

### 한계 (규칙만으로 정할 수 없는 것)
- **AI 판단 필요**: 거래정지 해제·기간 변경·불성실공시 당일 정지·풍문, 횡령 진행사항, 결과보고서처럼 R1 결정(PR #31)상 경보에서 빠지는 후속 공시는 AI가 원문에서 뽑는 값(`lifted`·`resolved`)으로 구분한다. 채점에서 빼고 따로 센다. 정정 공시는 같은 사건이라 새 신호로 넣지 않는다.
- **빠진 값**: 판정에 필요한 값(유상증자 비율·제3자배정 외에는 항목 API에서 바로 읽지 않음)은 비워 두고 기본 점수만 센다. 실제 흐름에서는 AI가 원문에서 채운다.
- **정정본 값**: DART 항목 API는 최신 정정본만 돌려줘서, CJ CGV 2023-06-20 유상증자처럼 공시 당일 값이 없는 경우가 있다. 나중 정정본 값은 미래 정보라 쓰지 않았다.

### 발견한 것 (R1·R4 확인 요청)
1. **금양 조기경보**: 감사의견 거절(2025-03-21)보다 **141일 앞선 2024-10-31**(제3자배정 유상증자, 같은 해 두 번째 유상증자)에 🟠 사건 경보가 처음 울린다. 감사의견 거절 날에는 🟠 사건 경보와 🟡 재무 경보(감사의견·단기채무·영업현금흐름)가 함께 켜진다. 맨 위 배지는 서버 우선순위상 🟠으로 보인다.
2. **CJ CGV는 새 규칙에서 🟠**: 2022-07 유상증자에 2023-06 유상증자(같은 종류 반복 가산)가 더해져, 발행 비율 값이 없어도 🟠 사건 경보가 된다. 이전 정답("유상증자 1건으로는 경보 없음")과 다르다 → 정답을 정해 주세요.
3. **현대차 오탐(복합 위험)**: 연결 재무제표에 금융 자회사의 차입금·영업현금흐름이 들어가 🟡 지표(단기채무·영업현금흐름 적자)가 쌓이고, 해외 상장폐지(자진) 2건·자기주식 처분이 더해져 복합 위험 기준을 넘는다. 금융업을 가진 회사의 연결 기준·자진 해외 상장폐지 처리를 규칙에서 볼 필요가 있다.
4. **풍문 거래정지 → 관찰 중**(R3 위니아 타임라인 2023-10-04)은 제목만으로는 계산되지 않는다. AI가 정지 사유를 뽑아야 한다.
