2. **사건·참고:** 사실확인의 첫 관측은 RED 후보이며, 확정 event_id가 같은 공시는 기존 사건 갱신 규칙을 사용한다. 정정은 최초 발생일을 바꾸지 않는다. 자회사·종속회사 공시는 점수에서 제외하고 조회·종목 타임라인에 `reference_only`를 제공한다. 제목만으로 사건을 자동 연결하거나 해소하지 않는다.
3. **R2 실제 포트 연결:** `agent.hosted:build_runtime` 선택 시 R4 조립이 실제 UnifiedBindings를 주입한다. 수치값은 R3가 저장한 확정 사실에서 매핑하며 필수 수치·단위·다중 행 확인 실패는 중단한다. hosted 경로는 구형 모델/근거 보정 wrapper를 사용하지 않는다. R4 체크포인터 주입, 공개 DB 발행, 조직별 초안 저장과 기존 승인 트랜잭션을 연결했다. 단독 실행기의 `--factory`도 조립 설정에 전달한다.
4. **누적 예산:** analysis_jobs·organization_reviews에 execution_budget JSON을 추가했다(`20261023_06`). 모델 요청·실행 시간·도구 입력별 호출을 저장하고 재시도·검토 claim 버전 변경 후에도 이어 쓴다. 임대 토큰을 검사하며 예산 소진·임대 상실 후에도 RAG holder 해제는 허용한다. 토큰은 실행 context의 내부 필드이며 R2·모델·공개 응답에 보내지 않는다.

6. **문서:** R4 소유 계약·실행 안내에 실제 연결과 한계를 적었다. 이전 Critical·P1/P2 기록과 현재 감사의견 YELLOW 기준을 구분했다.
