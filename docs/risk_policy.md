# 위험 정책 확정본

> 담당: **R1**. 점수표 값과 경보 기준을 확정해 적는 곳이다. 확정된 값은 R4가 `risk_engine/rules.yaml`에 반영한다.
> 경보 기준값(🟠 4점, 🟡 5점, 복합 1.5, 관찰 75%)은 [Phase 1 MVP 설계서](dartch_phase1_mvp.md)의 초안 값이 최신이다. 이 문서는 그 위에 **판단 원칙**과 **R1 결정(2026-10-23)** 을 더한다.
> 다른 담당에게 가는 요청은 [r1-decisions-requests.md](tasks/r1-decisions-requests.md)에 따로 모았다.

## 1. 판단 원칙

시스템의 목적은 **우리가 세운 기준과 AI가 판단한 기준으로 위험도를 측정하고, 그 결과로 경보를 주는 것**이다. 이 범위를 넘는 맥락의 판단은 시스템이 하지 않는다.

1. **미탐이 오탐보다 심각하다.** 경보를 줄 필요가 없는 회사에 경보를 주는 것보다, 경보를 줘야 하는 회사에 주지 않는 것이 더 큰 문제다. 애매하면 경보 쪽(또는 최소한 관찰 중)으로 둔다.
2. **기준 밖의 맥락은 규칙으로 걸러 내지 않는다.** 금융 자회사의 차입금이 연결 재무에 섞이는 경우, 자진 해외 상장폐지 같은 사정은 우리 기준과 AI 판단으로 설명할 수 없다. 이런 이유로 경보를 **제외하지 않는다.** 경보는 그대로 주고, 어떤 근거로 켜졌는지 보여 주어 **PB가 판단하거나 PB가 새 기준을 세운다.**
3. 오탐은 **허용한 비용**이다. 평가에서는 적중(경보가 있어야 할 곳에서 울린 수)을 먼저 보고, 오탐은 원인과 함께 설명한다.
4. 새 기준이 필요하면 코드에 예외를 넣지 않고 이 문서에 먼저 적은 뒤 `rules.yaml`에 반영한다.

## 2. 확정한 기준값

| 항목 | 값 | 비고 |
| --- | --- | --- |
| 🟠 경보 | 4점 이상 | 설계서 초안 유지 |
| 🟡 경보 | 5점 이상 | 설계서 초안 유지 |
| 복합 위험 | (🟠÷4)+(🟡÷5) ≥ 1.5 | 설계서 초안 유지 |
| 관찰 중 | 경보 기준의 75% (🟠 3점, 🟡 3.75점) | 반올림하지 않음 (R4 설계 결정 4) |
| **이자보상배율** | **1 미만 +2, 계산식 `영업이익 ÷ 금융비용`** | 분모는 손익계산서 `금융비용`/`금융원가`. 계정을 못 찾으면 0점이 아니라 "산정 불가". **R4는 자동 가점을 켠다** (`enabled:false` 해제) |
| 같은 지표의 점수 구간 | 가장 높은 구간 하나만 적용 | 독립된 조건은 합산 (R4 설계 결정 1) |

한계: 금융비용에는 이자 외 손익이 섞여 분모가 커지므로 이자보상배율이 낮게 나올 수 있다. 원칙 1·2에 따라 **과경보 쪽 오류로 보고 받아들인다.** 경보가 났을 때 근거에 계산에 쓴 값을 보여 PB가 확인하게 한다.

## 3. 사안별 결정

### 3-1. 위험 항목 분류

| 사안 | 결정 |
| --- | --- |
| 거래정지 — 풍문·보도 조회 | 🔴에서 제외, **관찰 중**. 제외가 아니라 관찰로 남긴다 |
| 거래정지 — `매매거래정지및정지해제(풍문등조회공시)` (정지·해제가 한 건) | **관찰 중**. 경보에서 빼지 않는다 |
| 관리종목 | **🔴.** 단독 제목(`관리종목지정`)이 없어도 변형 제목(`…관리종목지정ㆍ형식적상장폐지ㆍ상장적격성실질심사사유발생` 등)까지 인식한다. 오탐은 PB가 확인한다 |
| 횡령·배임 — 신규(`횡령ㆍ배임혐의발생`) | **🔴** (기존 결정 유지) |
| 횡령·배임 — `횡령ㆍ배임사실확인` | **이미 켜진 같은 사건의 🔴가 있으면 타임라인에만 붙이고, 첫 관측이면 🔴를 새로 켠다.** 앞선 공시를 못 본 경우의 미탐을 막는다. 같은 원칙을 다른 후속 공시에도 쓴다 |
| 자회사·종속회사 공시 | 제목의 `자회사`·`종속회사` **두 표기를 모두 인식**한다. 점수·단계에는 반영하지 않지만(기존 결정 유지), PB가 볼 수 있게 **참고로 표시**한다 |
| 무상증자 | 점수표에 기준이 없으므로 **수집하지 않는다** (범위 밖) |
| 실제 원리금 미지급 | **🔴 포함 방향으로 확정.** 구현 방식은 R4 회신(비용)에 따른다. 비싸면 **근거를 남기고 알림은 준다.** 단순 미상환 잔액·만기 도래와는 구분한다 |

### 3-2. 재무 지표

| 사안 | 결정 |
| --- | --- |
| 자본잠식 기준 | **개별(OFS)·연결(CFS)을 둘 다 계산**하고, **하나라도 기준을 넘으면 켠다.** 점수는 두 값 중 높은 구간 하나만 적용하고, 근거에 어느 기준(`fs_div`)으로 켜졌는지 표시한다. 자본잠식률 = (자본금−자기자본)÷자본금×100, 자기자본 ≤ 0이면 전액(100) |
| 금융업을 가진 회사의 연결 지표 | 규칙을 바꾸지 않는다. 경보는 유지하고, 어떤 지표가 켜졌는지 근거에서 구분해 보여 준다 (원칙 2) |

## 4. 알려진 한계

- 금융업 연결 지표, 자진 해외 상장폐지처럼 맥락이 필요한 판단은 시스템이 하지 않는다. PB가 근거를 보고 판단한다.
- 이자보상배율은 금융비용을 분모로 써서 낮게 나올 수 있다.
- 장중에 나온 공시는 다음날 아침에야 알게 된다 (수집 주기 1일 1회).
- 위의 한계를 숨기지 않고 발표의 한계 슬라이드에 넣는다.
